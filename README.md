# Ultrasonic-Sensor-Servo-Motor-project

Tinkercad Simulation:
https://www.tinkercad.com/things/gND3ih8b9B0/editel?returnTo=%2Fdashboard&sharecode=vnxJ2JfEGIdMKfi-2JfXH8O9BOxIWBhnVPYC7-TCOuU

The circuit uses an ultrasonic sensor to detect an obstacle at 10 cm.
When an obstacle is detected, the motor stops and changes direction,
and the servo motor changes its position.
